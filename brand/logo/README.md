# Logo de WorkBoard

Tres listas dentro de un cuadrado redondeado. La del centro es más corta y, juntas, dibujan la W de WorkBoard.

## Colores

- Blanco `#eef0f4` (el de las listas Blancas) y casi negro `#17181b` (superficies de la app).
- Principal: cuadrado blanco, listas casi negras, nombre en blanco.
- Fondos claros: cuadrado casi negro, listas blancas, nombre casi negro.
- Un color: listas recortadas, dejan ver el fondo.

## Uso

- Espacio libre alrededor: como mínimo el ancho de una lista del símbolo.
- Tamaño mínimo: 16 px de alto el símbolo y 20 px el logo horizontal.
- No estirar, girar, cambiar la altura de la lista central, añadir sombras ni colocar sobre fondos con mucho ruido.

## Nota técnica

El nombre usa la fuente del sistema (SF Pro) como texto. Antes de usar los SVG fuera de Apple (por ejemplo en la web o en impresión) hay que convertir el texto a trazados para que no dependa de la fuente instalada.
